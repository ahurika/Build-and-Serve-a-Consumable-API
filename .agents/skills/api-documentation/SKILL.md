# Skill: API Documentation

## Use when
Writing or updating README API documentation.

## Procedure
1. Enumerate every implemented endpoint.
2. For each endpoint document method and path.
3. Document query parameters with types and defaults.
4. Add a copy-pasteable curl request.
5. Add an example response.
6. Document error behavior.
7. Document pagination/filtering/sorting.
8. Add Design decisions.
9. Explain generated identifiers.
10. Explain pagination choice and tradeoff.
11. Explain response envelope.
12. Verify the README instructions against the deployed API.

## Acceptance
A developer who has never spoken to the author can use the API from README alone.
