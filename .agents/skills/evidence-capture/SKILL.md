# Skill: Evidence Capture

## Use when
Proving Task 1 requirements.

## Required artifacts
1. Live API URL.
2. Terminal screenshot of curl against live API with pagination.
3. Screenshot of 429 after exceeding rate limit.
4. Screenshot of consumer displaying live API data.
5. Seed script in repository.

## Procedure
For each evidence item:
- Run the real implementation.
- Capture the actual result.
- Record what requirement it proves.
- Keep the screenshot readable.
- Do not create synthetic evidence.
