# Skill: API Design

## Use when
Designing resources, relationships, routes, HTTP methods, response contracts, pagination, filtering, and sorting.

## Procedure
1. Read PRD requirements R1–R17.
2. Identify 3–5 related resources.
3. Define resource fields and requiredness.
4. Select generated identifiers.
5. Define collection/item routes.
6. Define nested route(s) where applicable.
7. Define list query contract.
8. Define response envelope.
9. Define error envelope.
10. Check every list endpoint against pagination, filtering, and sorting.
11. Record unresolved implementation choices.

## Output
A concrete API contract that can be documented and implemented without inventing requirements.
