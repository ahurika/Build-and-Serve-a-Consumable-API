# Skill: Public Deployment

## Use when
Deploying and externally verifying the API.

## Procedure
1. Read R23–R27.
2. Configure managed Postgres.
3. Configure environment variables.
4. Deploy API.
5. Run production seed.
6. Verify public endpoints from outside local development.
7. Record live URL.
8. Configure consumer to use public URL.
9. Verify consumer from the deployed API.
10. Capture required evidence.

## Security
Never commit `.env` or real credentials.
