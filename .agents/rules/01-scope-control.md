# Rule: Scope Control
Scope:
- Public REST API.
- Realistic relational data.
- Minimal public API consumer.
- Required documentation, deployment, validation, rate limiting, and evidence.

Never build:
- Landing pages.
- Admin panels.
- Reading authentication.
- Unrequested application features.

If a proposed feature is not required by the brief, do not build it unless it is strictly necessary to satisfy an explicit requirement.
