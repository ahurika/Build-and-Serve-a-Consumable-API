# Rule: API Documentation
README is the API documentation.

For every endpoint include:
- Method.
- Path.
- Query parameters, types, defaults.
- curl example.
- Example response.

Include a Design decisions section covering:
- Resource choices.
- Generated identifiers.
- Pagination choice.
- Response envelope and rationale.

A developer unfamiliar with the project must be able to use the API from the README alone.
