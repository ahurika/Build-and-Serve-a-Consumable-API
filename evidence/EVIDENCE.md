# Evidence Checklist

This folder contains the artifacts required for final submission. Since deployment to a live URL (Vercel, Railway, etc.) happens locally, please use this checklist to track the final required pieces of evidence.

### Required Evidence files:

- [x] **`seed.ts`**: The repeatable database seed script (already copied into this folder).
- [x] **`live_api_url.txt`**: A text file containing the public URL to your deployed API.
- [ ] **`curl_pagination.png`**: A screenshot of a curl command hitting the live URL from a terminal, showing a paginated response.
- [ ] **`rate_limit_429.png`**: A screenshot of the `429` response after exceeding the rate limit.
- [ ] **`consumer_app.png`**: A screenshot of the Next.js consumer displaying data from the live API.

Once you have deployed your application and database, generate the screenshots and drop them into this `evidence/` folder.
